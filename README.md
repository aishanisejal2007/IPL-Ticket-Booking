
# IPL Ticket Booking Website 🏏

## About the Project
A simple IPL 2026 Ticket Booking Website created using HTML and CSS.

## Activities

### Activity 1: HTML Structure
- Navigation Bar
- Hero Section
- About IPL 2026
- Match Schedule
- Team Filter
- Ticket Booking Form
- Booking Summary
- My Bookings
- Booking Guidelines
- Footer

### Activity 2: CSS Styling
- CSS Variables
- Fixed Navigation Bar
- Gradient Hero Section
- Styled Buttons
- Responsive Layout
- Styled Tables and Forms
- Cards and Shadows
- Hover Effects

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
